# 虚拟老师形象

这个目录放**图片形象**（`kind: 'image'` 的角色）。矢量形象不需要任何素材文件，直接由
`src/components/TeacherAvatar.vue` 画出来。

---

## 目录约定

```
public/avatars/
  <角色id>/
    idle.webp           必填（其他状态缺失时都回退到它）
    listening.webp      可选
    thinking.webp       可选
    speaking.webp       可选
```

`<角色id>` 要和 `src/data/teacherCharacters.js` 里那一项的 `id` 完全一致。

## 图片规格（建议）

| 项 | 建议值 | 说明 |
|---|---|---|
| **比例** | **4:5 竖版**（如 1024×1280） | 形象卡是竖版（176×220）。**这是半身像的关键** —— 方图或圆图只能塞下一颗头 |
| 构图 | **头顶落在画面上 10% 左右**，胸口以上入镜 | 头顶别贴边，也别留一大片空白；肩、胸要看得见 |
| 尺寸 | 长边 1024~1536 | 卡片 176×220，2.5 倍图就够清晰 |
| 格式 | **WebP**（q85） | 同画质比 PNG 小 60~80% |
| 体积 | **单张 ≤ 80 KB** | 开源仓库友好 |
| 背景 | **与人物分离度高的纯色/柔和渐变** | ⚠️ 别用接近肤色的奶油/米色 —— 人物会和背景糊在一起，缩小后更看不清 |
| 视线 | 看镜头，表情自然 | 缩小到 176px 时表情是唯一能传达性格的东西 |

处理脚本：`tools/avatar_portrait.py`（自动找头顶 → 裁 4:5 → 输出 440×550 WebP）。
`tools/avatar_check.py` 可以在出图后先做一次程序化体检（清晰度 / 亮度 / 主体位置）。

---

## 接一个图片形象

1. 建目录并放图：`public/avatars/<id>/idle.webp`
2. 在 `src/data/teacherCharacters.js` 的 `CHARACTERS` 里加一项：

```js
{
  id: 'sofia',
  name: 'Sofia',
  role: '英语会话老师',
  tag: '真人感 · 自然口语',
  kind: 'image',                       // ← 关键
  lang: 'en-US',
  tts: { provider: 'edge', voice: 'en-US-AvaMultilingualNeural' },
  images: { idle: '/avatars/sofia/idle.webp' },
  tint: '#3b82f6',                     // 状态光效色（可选）
}
```

3. 刷新即可。角色 chip 会自动换成缩略头像。

**只放 `idle` 就够用** —— 另外三个状态缺了会自动回退，状态差别由动效表达
（聆听＝红色描边呼吸、思考＝降饱和＋暖色描边、说话＝呼吸缩放＋声波）。

## 状态是怎么表达的（写实图的取舍）

矢量形象可以逐帧改口型（`.lip` 缩放）。**写实/插画图做不到**，除非你为每个音素出图。
所以图片形象走「整体动效」路线：

| 状态 | 效果 |
|---|---|
| idle | 缓慢上下浮动（5s） |
| listening | 外圈红色脉动 + 环形描边 |
| thinking | 虚线环旋转 + 画面降饱和 |
| speaking | 呼吸式缩放（0.75s）+ 底部声波扩散 |

**想更讲究**，可以自己出 `speaking` 变体图（同一人物、嘴微张），系统会自动用上；
但要注意人物一致性 —— 这是写实形象最容易翻车的地方，建议同一 seed / 同一参考图生成。

## 版权与开源注意事项 ⚠️

- **不要提交**：真人照片、明星/网红肖像、影视截图、来源不明的网络图片。开源仓库会被 fork 和再分发，
  这类素材会带来肖像权与著作权风险。
- **可以提交**：自己拍摄并授权的照片、自己绘制的插画、明确许可的开源素材、
  AI 生成的原创虚构人物（注意各生成平台的商用条款）。
- 仓库**默认只带矢量形象**，就是为了 clone 下来零风险、零素材依赖。
  图片形象属于「使用者自行添加」的扩展位。
- 建议为每张图在 `<id>/CREDIT.txt` 里注明来源与许可，方便后来者判断能否复用。
