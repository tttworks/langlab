# langlab · 语言学习器

> **本地优先的多语种学习系统** —— 用自己的真实材料学语言。
> 卡片 · 间隔重复 · 划词建卡 · 内嵌阅读器 · AI 虚拟老师 · 本地发音诊断

**它不教你语言，它训练你用自己的材料。**

市面上的语言 App 教的是它们的课程；langlab 训练的是**你自己的材料** ——
工作合同、行业 Memo、外文剧集、电子书。划词就建卡，卡片自动排期复习，
还有一个虚拟老师能听你念、指出你在哪里卡壳。

**所有数据都在你自己的机器上：不上传、不订阅、不锁定。**

---

## 它适合谁

- 有大量真实外文材料要「吃透」的从业者（法律 / 投资 / 医疗 / 工程……）
- 在意数据主权、不接受云账号的人
- 已经「会一点」但**取不出来、说不顺**的学习者

**它不适合**：从零开始学一门语言的人（那请先用 Duolingo / Babbel 打基础）。

---

## 功能

| 模块 | 说明 |
|---|---|
| **卡片学习器** | 6 种卡片类型；接受性 / 产出性（中→英）双模式；随机抽、乱序、标记掌握 |
| **间隔重复** | SM-2 调度（内置 FSRS 迁移所需的复习流水记录） |
| **阅读器** | EPUB / PDF 内嵌原版 + 精读批注双模式；逐句朗读；跟读横线 |
| **划词建卡** | 阅读中选中文本 → 一键成卡（可选 AI 自动补释义与音标） |
| **虚拟老师** | 多角色对话 + **本地发音诊断**（whisper 词级分析：念错 / 含糊 / 卡壳 / 漏读） |
| **素材库** | 上传文件 / 登记本地路径 / 粘贴文本 / 网址抓取；支持影视剧集三级浏览 |
| **数据大盘** | 学习指标 + 分阶段对比 + 热力图 |

## 快速开始

**环境**：PHP 8.2+、Node 18+，以及（可选）Python 3.11+ 用于发音诊断与语音合成。

```bash
# 1) 后端依赖
cd backend && composer install

# 2) 配置（所有 Key 都是可选的，不填也能跑）
cp data/.env.example data/.env

# 3) 建库 + 导入演示卡片
php scripts/migrate.php
php scripts/seed_demo.php      # 可选：导入一组演示卡，先看看效果

# 4) 前端
cd ../frontend && npm install && npm run dev
```

浏览器打开 <http://localhost:5174>。

## 它不做什么

- **不做课程** —— 不提供从零到流利的教学内容，你需要自备材料
- **不做云同步** —— 数据在本机；多处使用请自行处理
- **不联网也能用** —— 除 AI 对话外，卡片、阅读、复习、发音诊断全部离线
